# imagesensor_3dmodel

Sensor Lab · 이미지 센서 3D 학습 뷰어

일반화한 BSI CMOS 이미지 센서를 회전·확대하고, 구조와 동작을 배우는 한국어 웹 앱입니다.

## 실행

Node.js 22.12 이상과 최신 Edge 또는 Chrome을 권장합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 엽니다. 배포용 정적 파일은 `npm run build`로 `dist/`에 생성합니다. `npm run preview`로 빌드 결과를 확인합니다.

## 기능

- 센서 패키지, 8×8 베이어 픽셀 배열, 2×2 픽셀 단면 개념 모델
- 마우스 회전·확대·이동, 자동 회전 및 시점 초기화
- 분해 슬라이더, 부품 클릭·선택, 층별 표시 전환
- 빛 입사 → 전하 축적 → 신호 읽기 → 디지털 변환의 단계별 설명 및 애니메이션
- 빛 세기와 노출 시간을 조절하는 상대 전하량 실험
- 이해 확인 퀴즈, 현재 표시 모델의 GLB 다운로드
- 모바일 반응형 레이아웃, 선택적인 WebMCP 도구

## 교육 모델의 범위

특정 제품이나 공정을 재현한 설계도가 아닙니다. 렌즈, 컬러 필터, 실리콘/포토다이오드, 배선, 지지층을 이해하기 위해 크기와 층 간격을 과장했습니다. 포토다이오드 표시는 실리콘 내부 활성 영역의 위치를 설명하는 단순화입니다. 픽셀 단면은 2×2 픽셀의 층 구조 개념 표현이며 도핑 프로파일이나 트랜지스터 상세 단면을 구현하지 않습니다.

실험식은 `min(100, 빛 세기 × 노출 시간 / 20)`의 상대값으로, 양자 효율·암전류·노이즈·실제 포화 전자 수를 계산하지 않습니다. 전하 애니메이션도 이동과 읽기 과정을 단순화한 시각적 설명입니다. ADC는 개별 픽셀 내부 모델에 포함하지 않았으며 디지털 변환 이후 디모자이킹은 아직 구현하지 않았습니다.

## 모델 수정

`src/main.ts`의 `rebuild()`에서 Three.js 형상을 생성합니다. Blender 설치 없이 수정할 수 있으며, 뷰어에서 받은 GLB는 Blender로 가져올 수 있습니다. 분해 상태와 표시 중인 층이 다운로드 모델에 반영됩니다.

- `src/main.ts`: 학습 콘텐츠, 3D 모델, UI 상태와 상호작용
- `src/style.css`: 데스크톱·모바일 화면
- `tests/viewer.spec.mjs`: 핵심 사용자 흐름 검증

## 검증

미리보기 서버를 실행한 상태에서 `npx playwright test`를 실행합니다. 테스트는 설치된 Microsoft Edge를 사용합니다. 다른 운영체제에서는 `playwright.config.mjs`의 브라우저 채널을 조정할 수 있습니다.

## 패키지·회로 상세 (두 번째 버전)

첫 화면에서 패키지·회로 기능 배치도를 보여줍니다. 기존 센서 전체 / 픽셀 배열 / 픽셀 단면 화면도 유지합니다.

추가한 항목은 행 드라이버, 열 신호선·CDS/PGA, 열 ADC 뱅크, 타이밍·레지스터·PLL, 전원·바이어스, 디지털 출력, 광학 블랙 영역, 다이 패드·ESD, 본딩 와이어, 기판 배선·비아, 하부 LGA 접점, 지지체·다이 접착층, 패키지 기판, 실링 프레임, 광학 커버입니다. 각 항목은 3D 클릭 또는 목록 선택으로 설명·연결 관계를 확인하고 개별 표시를 전환할 수 있습니다.

회로 영역은 지지체와 구분해 센서 다이 측에 배치했습니다. BSI 회로면을 펼쳐 보여주는 기능 배치도이며 실제 공정 단면, 적층 로직 다이 또는 특정 칩의 플로어플랜이 아닙니다. 광학 블랙 띠와 활성 픽셀 위치도 기능적 위치 표현입니다. 상세 화면에서는 광학층을 생략합니다. 센서 전체 화면에서 광학층을 관찰할 수 있습니다.

패키지는 와이어 본딩 + 평면 하부 접점의 예시입니다. 40개 접점과 금속 배선은 임의의 교육용 배열이며 실제 핀맵·배선층·재료를 의미하지 않습니다. 본딩 곡선은 분해 시 전기 연결 관계를 유지하도록 변형되며 실제 와이어의 신축을 뜻하지 않습니다. 유리 커버는 기본 숨김이며 표시할 수 있습니다. 개별 회로 블록과 패키지는 GLB 다운로드에도 포함됩니다.

`node tests/package-model.mjs`는 브라우저 없이 회로/패키지 소속, 본딩 끝점 정합, 분해 상태별 유한 좌표, 표시 전환 및 하부 접점을 검증합니다. 실행 과정에서 임시 모듈을 무시되는 `.sites-runtime/`에 생성합니다.

## 셔터·읽기 동작 학습

시작 화면의 **셔터·읽기 동작**에서 롤링/글로벌 셔터를 전환하고 재생·일시정지·이전/다음 단계·시간 탐색을 사용할 수 있습니다. 하단의 행별 시간표 또는 3D 모델의 픽셀 행을 누르면 해당 행의 읽기로 이동합니다. 속도와 노출 길이도 변경할 수 있습니다.

- 롤링: R1~R8의 PD 리셋과 노출 창이 1 Tline씩 이동합니다. 이전 행의 읽기와 다음 행의 PD 리셋이 겹치는 상태를 별도로 표시합니다.
- 글로벌: 전하 저장형 픽셀을 예로 들어 모든 PD의 노출 종료와 MEM 저장이 동시에 일어납니다. 저장된 신호는 행별 SEL → FD 리셋/기준 샘플 → MEM에서 FD로 전달 → 신호 샘플/CDS → ADC → 출력 순서로 읽습니다.
- 롤링의 읽기는 FD 기준 샘플 후 PD→FD 전달 시 해당 행의 노출이 끝나는 것으로 모델링했습니다. 글로벌의 PD→MEM 전체 전달과 MEM→FD 행별 전달을 구분합니다.
- 열 배선을 따라 움직이는 청록색은 전압 신호, 픽셀 내부의 노란 점은 전하 전달, 보라색 작은 칸은 픽셀의 차광 MEM을 나타냅니다.
- ADC는 8개의 대표 열이 공통 램프/카운터를 사용하고, 입력에 도달한 카운트를 열별로 래치하는 8비트 단일 경사 예시입니다. 최종 코드와 외부로 출력 완료된 행을 보여줍니다.

시간 단위 Tline, 노출 길이, 전압, 픽셀 값, 8비트 해상도, 파형 지속 시간은 모두 교육용입니다. 글로벌 리셋 릴리즈(GRR), 전압 저장형 글로벌 셔터, 다른 CDS 방식, 실제 ADC 공유·병렬화 비율, 전송 레인과 프레임 중첩은 별도 주제입니다. BSI 단면과 셔터 방식은 독립적인 개념이며 이 모델의 전체 구조를 특정 제품으로 해석해서는 안 됩니다. 애니메이션 마커는 GLB 모델 내보내기에서 제외합니다.

`node tests/readout-model.mjs`는 글로벌 노출 정렬·MEM 보존, 롤링 노출 차이·리셋/읽기 중첩, 8개 행의 샘플/CDS/ADC 순서, 비교기 래치와 프레임 완료를 검증합니다. `npx playwright test`는 조작·일시정지·행 선택·코드 출력과 기존 뷰어 동작을 검증합니다.
